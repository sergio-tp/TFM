# Evolution of Housing Sales and Prices in Spain

Centralized data warehouse, ETL pipeline and analysis developed as a Master's Thesis for the Master's Degree in Big Data, Artificial Intelligence and Data Engineering.

## Repository Structure

* `etl_process/`: Python and PySpark cleaning scripts for raw datasets, and Pentaho transformations and jobs for data integration
* `datasets/`: Original public datasets from INE and MIVAU.
* `datasets_def/`: Cleaned and processed CSV outputs ready for database loading.
* `analysis/`: Jupyter notebooks for data analysis and images of the visualizations.
* `DDL_Oracle_Database.sql`: Script for generating and structuring the database in Oracle.
* `requirements.txt`: Python package dependencies for reproducibility.
* `README.md`: Project documentation and architectural overview.
